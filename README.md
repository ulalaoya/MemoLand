# MemoLand — עולם של זיכרון, כל יום 🧠

אפליקציית אימון קוגניטיבי לילדים, בעברית מלאה (RTL), בנויה כמסע במשחק פלטפורמות בשם **ממו לנד**. הילד לא "פותר תרגילים" — הוא **מטייל בממו לנד**, כובש ארצות, מניף דגלים ופותח טירות.

> **הבהרה:** האפליקציה היא כלי לתרגול והעשרה, לא כלי אבחון או הערכה קוגניטיבית. הנתונים בדשבורד ההורים משקפים תרגול באפליקציה בלבד.

---

## מה בפנים (שלב נוכחי)

- **שלד מלא** של 6 הארצות, המפה, הסשן היומי, מנוע ההתאמה, החזרות במרווחים, התגמולים, ודשבורד ההורים.
- **שתי ארצות עובדות end-to-end:**
  - **עמק המספרים** (זיכרון עבודה): רצף ספרות קדימה, רצף הפוך, מיון רצף, חשבון בשרשרת.
  - **מערת ההדים** (זיכרון שמיעתי): הקשב וחזור, הוראות מרובות שלבים.
- **ארצות 3–6** מסומנות "בקרוב" במפה — התשתית מוכנה, צריך רק להוסיף להן מנועים (ראה למטה).
- **פרופילי משתמשים** — כמה ילדים באותו מכשיר, לכל אחד התקדמות נפרדת לגמרי. מסך "מי משחק היום?" בכניסה, והחלפת משתמש מהצ'יפ בראש המפה.
- **קול עברי** — כל ההקראה השמיעתית ב-he-IL; אפשר לבחור קול ולבדוק אותו בהגדרות ההורים, עם התרעה אם אין קול עברי מותקן במכשיר.
- כל הגרפיקה היא **SVG מקורי** (ממו, המדריכים, האייקונים, הרקעים) + תמונת הירו; בלי אימוג'י מערכת ובלי נכסים חיצוניים.
- **PWA**: ניתן להתקנה למסך הבית, עובד ללא רשת אחרי טעינה ראשונה.

## הרצה מקומית

```bash
npm install
npm run dev
```

האפליקציה תעלה על `http://localhost:5173` (או הפורט שיוקצה). פותחים בדפדפן — עדיף במצב מובייל / רוחב מסך של טלפון.

### בדיקות

```bash
npm test
```

מריץ את כל בדיקות ה-Vitest: כל מנוע תרגיל (אין פריט בלתי פתיר, התשובה נגזרת מהגירוי, דטרמיניזם), אלגוריתם המדרגה, ומתזמן החזרות.

### בנייה לפרודקשן

```bash
npm run build
```

התוצר נכתב לתיקיית `dist/` — קבצים סטטיים בלבד.

## פריסה — GitHub Pages (אוטומטית)

הפרויקט כולל workflow מוכן ב-[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) שבונה ופורס אוטומטית בכל דחיפה ל-`main`.

**התקנה חד-פעמית:**
1. יוצרים ריפו חדש ב-GitHub ודוחפים את הפרויקט (ראה למטה).
2. ב-GitHub: **Settings → Pages → Source → GitHub Actions**.
3. כל `git push` ל-`main` יבנה ויפרוס. הכתובת: `https://<שם-משתמש>.github.io/<שם-ריפו>/`.

**דחיפה ראשונה:**
```bash
git init
git add .
git commit -m "MemoLand"
git branch -M main
git remote add origin https://github.com/<שם-משתמש>/<שם-ריפו>.git
git push -u origin main
```

התוצר סטטי (`base: './'`, נתיבים יחסיים), כך שהוא רץ גם מכל אחסון סטטי אחר (Netlify Drop / Vercel) אם תעדיף — פשוט מעלים את תוכן `dist/` אחרי `npm run build`.

### התקנה למסך הבית בטלפון

- **iOS (Safari):** כפתור השיתוף → "הוסף למסך הבית".
- **Android (Chrome):** תפריט ⋮ → "התקן אפליקציה" / "הוספה למסך הבית".

לאחר ההתקנה האפליקציה נפתחת במסך מלא ועובדת גם ללא רשת.

## הערה על קול (iOS)

ב-iOS מנוע ההקראה (`SpeechSynthesis`) חייב להתעורר מתוך מגע ראשון. לכן כל סשן נפתח במסך **"הקש כדי להתחיל"** שמאתחל את הקול ואת אפקטי ה-Web Audio. אין באפליקציה זיהוי דיבור (לא אמין בעברית) — כל תרגיל שמיעתי נבדק בבחירה/סידור אריחים על המסך.

---

## דשבורד הורים

- **כניסה:** לחיצה ארוכה (≈0.75 שנייה) על הלוגו בראש המפה → הזנת קוד בן 4 ספרות.
- **קוד ברירת מחדל:** `1234` (ניתן לשינוי בהגדרות בתוך הדשבורד).
- כולל: מדדי התקדמות לפי ארץ, span ספרות מרבי, דקות תרגול, רצף ימים, עקביות, גרף מגמה, המלצות שבועיות (מנוע כללים דטרמיניסטי — לא LLM), ניהול תוכן, הגדרות, וייצוא/ייבוא/איפוס נתונים.

## מבנה הפרויקט

```
src/
  engines/       # מנוע generator טהור לכל תרגיל: (level, seed) => Challenge
  config/        # curriculum.ts (פרמטרי רמות) + lands.ts (מטא הארצות)
  state/         # store התקדמות + שכבת persistence (localStorage)
  scheduler/     # בניית הסשן היומי + חזרות במרווחים + מדרגה + המלצות
  audio/         # speech (SpeechSynthesis) + sfx (Web Audio)
  components/    # UI + SVG מקורי + רכיבי המשחקים
  screens/       # מסכי-על: Start / Map / Session / Treasure / ParentDashboard
```

מנועי התרגילים **מנותקים לחלוטין מה-UI** וניתנים לבדיקה עצמאית.

## הרחבה — הוספת ארץ / אתגר

1. כותבים מנוע ב-`src/engines/<land>.ts` שמממש `ExerciseEngine` (עם `generate` ו-`check`).
2. מוסיפים אותו למערך `ENGINES` ב-`src/engines/index.ts`.
3. מוסיפים רכיב משחק ב-`src/components/games/` ומחברים אותו ב-`GameHost.tsx` לפי `exerciseId`.
4. אם צריך, מוסיפים פרמטרי רמות ב-`src/config/curriculum.ts`.

המפה, הסשן היומי, אלגוריתם ההתאמה והדשבורד יזהו את המנוע החדש אוטומטית.
